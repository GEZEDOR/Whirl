# Учебный проект вёрстки

Статичный сайт на **HTML + CSS** без сборщиков и фреймворков. Здесь уже заложена структура, по которой удобно **добавлять блоки**, **подключать стили** и **делать адаптив** — ниже по шагам, что за что отвечает и как развивать проект дальше.

## Как открыть проект

1. Склонируйте или скачайте папку проекта.
2. Откройте файл `index.html` в браузере (двойной клик или «Open with Live Server» в VS Code / Cursor).
3. Для комфортной разработки лучше использовать расширение **Live Server** — страница будет обновляться при сохранении файлов.

Сборка (`npm install`, webpack и т.п.) **не нужна**.

## Структура папок

```
exercise/
├── index.html              # разметка страницы
├── css/
│   ├── global/             # общие стили для всего сайта
│   │   ├── index.css       # точка входа глобальных стилей
│   │   ├── fonts.css       # подключение шрифтов
│   │   ├── null.css        # сброс стилей браузера
│   │   └── variables.css   # CSS-переменные (цвета и т.д.)
│   └── pages/              # стили конкретной страницы
│       ├── index.css       # собирает все блоки страницы + медиазапросы
│       ├── common.css      # обёртка, main, контейнеры
│       ├── header.css      # стили шапки
│       ├── get-started.css # стили первого блока (нужно создать)
│       ├── footer.css      # стили подвала (нужно создать)
│       └── media/          # адаптив по ширине экрана
│           ├── media1200.css
│           ├── media768.css   # нужно создать
│           ├── media580.css   # нужно создать
│           └── media380.css   # нужно создать
├── fonts/                  # файлы шрифтов (.ttf)
└── images/                 # картинки и иконки
```

В `index.html` подключаются **только два** файла:

```html
<link rel="stylesheet" href="./css/global/index.css" />
<link rel="stylesheet" href="./css/pages/index.css" />
```

Остальные CSS подтягиваются через `@import` внутри этих двух файлов. **Не добавляйте** десятки `<link>` в HTML — добавляйте импорт в `css/pages/index.css`.

## Каркас страницы в HTML

Вся страница обёрнута в `.wrapper` — колонка на всю высоту экрана, чтобы **подвал прижимался к низу**, а контент рос в `main`:

```html
<div class="wrapper">
  <header class="header">...</header>
  <main class="main">...</main>
  <footer class="footer">...</footer>
</div>
```

- **header** — шапка с логотипом и меню (уже есть пример).
- **main** — основной контент: секции `<section>`.
- **footer** — подвал (пока заглушка, стили — в `footer.css`).

Каждая крупная секция — отдельный блок с **своим CSS-файлом** (см. ниже).

## Именование классов (БЭМ)

В проекте используется упрощённый **БЭМ**:

| Часть | Пример | Назначение |
|--------|--------|------------|
| Блок | `header`, `get-started` | Независимый компонент |
| Элемент | `header__logo`, `header__link` | Часть блока |
| Модификатор | `menu-buttons` (отдельный блок внутри header) | Вариант или вложенный блок |

## Контейнер и ширина контента

Для выравнивания по центру и ограничения ширины используется класс **`__container`** у блока:

```html
<section class="get-started">
  <div class="get-started__container">
    <!-- контент -->
  </div>
</section>
```

В `common.css` задано общее правило для **всех** контейнеров:

```css
[class*='__container'] {
  max-width: 1110px;
  margin: 0 auto;
}
```

Чтобы изменить ширину на всём сайте — меняйте `max-width` в `common.css` или в медиафайлах (например, в `media1200.css` контейнер уже сужается до 850px).

---

Для названий переменных в variables можно пользоваться [Color Namer](https://colornamer.robertcooper.me/).

## Адаптивная вёрстка (медиазапросы)

В `css/pages/index.css` медиафайлы подключены **условно** — браузер загрузит только нужный файл под ширину экрана:

```css
@import url('./media/media1200.css') (max-width: 1200px);
@import url('./media/media768.css') (max-width: 768px);
@import url('./media/media580.css') (max-width: 580px);
@import url('./media/media380.css') (max-width: 380px);
```
